# Examples for CMotive standard library object model

Examples 151-153 exercise the object-style standard-library APIs:

- `Vector`, `Dict`, and `BPlusTree` object methods from `Sys::STL`
- `Algorithms` class methods from `Sys::Algorithms`
- `OStream` and `Formatter` objects from `Sys::IO`

The examples intentionally avoid the older functional helper calls.
