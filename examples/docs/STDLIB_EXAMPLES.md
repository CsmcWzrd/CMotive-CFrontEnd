# Standard-library examples

The standard-library section covers `Sys::Stdio`, `Sys::Logging`, `Sys::File`, `Sys::Filesystem`, `Sys::Thread`, `Sys::Net`, and `Sys::STL` source shapes. Runtime-heavy areas such as real file handles, sockets, userspace scheduler behavior, and STL containers remain scaffolded in the current CMotive compiler/runtime and are therefore represented by compile-safe examples.


Added examples 138-145 for Sys::IO rename, STL containers, Sys::Algorithms, native sockets, native threading, and Dynamic Struct Expand.
